Tool guide

💡 功能介绍与极速使用指南

不用注册、不用上传。安装后先在合成样例上跑通，再把三条路径换成年自己的报表即可。

1安装稳定 wheel

从 GitHub Release 直接安装 v0.1.0；需要读 xlsx 时使用 README 中的 amzleak[xlsx] 安装命令。

pip install "https://github.com/rinch-wu/amz-leak-audit/releases/download/v0.1.0/amzleak-0.1.0-py3-none-any.whl"

2生成样例并跑通

先确认安装、解析和总账输出正常，再处理自己的文件。

amzleak sample -o demo
amzleak ledger --settlement demo/settlement-sample.tsv --inventory demo/inventory-age-sample.csv --ppc demo/search-term-sample.csv

3换成自己的报表

从 Seller Central 导出结算、库存龄期、搜索词报表，替换下面三个路径。

amzleak ledger --settlement "path/to/settlement.tsv" --inventory "path/to/inventory-age.csv" --ppc "path/to/search-term.csv"

Single report

一份报表也能查

不用等三份报表齐备。任一子命令都支持 --json，结算、库存龄期和搜索词还支持用 --out 写出动作文件。

结算漏损

检查重复扣费、异常佣金和退款，输出三类最大漏损。

amzleak settlement demo/settlement-sample.tsv --json
amzleak settlement demo/settlement-sample.tsv --out settlement-actions.csv
动作文件：settlement-actions.csv

库存龄期

计算压死资金、长期仓储费敞口，并给出清货或移除建议。

amzleak inventory demo/inventory-age-sample.csv --json
amzleak inventory demo/inventory-age-sample.csv --out inventory-actions.csv
动作文件：inventory-actions.csv

搜索词空耗

找出高花费零转化词与 ACOS 倒挂词，生成批量否定词清单。

amzleak ppc demo/search-term-sample.csv --json
amzleak ppc demo/search-term-sample.csv --out negatives.tsv
动作文件：negatives.tsv

Scope

口径与假设

三个金额不是同一种钱。把口径拆开，才能知道哪些能行动、哪些只是占用、哪些已经发生。

指标含义使用方式
可追回现金本周期结算白名单异常金额与广告保守可回收金额流量口径，可作为本期可行动金额
被压死资金超过 90 天的库存按单件成本计算出的资金占用被压死资金不可与可追回现金相加
已流失难追回退款金额与广告倒挂亏损等已发生损失已发生，不代表还能追回
  • 零转化空耗保留 10% 品牌防守词，按 90% 估算可追回；ACOS 倒挂部分按降价后 70% 估算。
  • 库存单价与预期售价由你传入；默认 --unit-cost 8、--price 29.9，不代表真实成本。
  • 不同币种不做汇率换算；只有同币种金额会并入总账，混合币种会明确提示。
  • 库存 90 天以上为压死资金；365+ 库存会给出售卖与移除建议。

FAQ

常见问题

数据会不会上传？

不会。报表在本地解析，CLI 不联网、不上传、不埋点，也不会读取环境变量里的业务数据。

要不要注册？

不要。安装命令行工具即可使用，不需要账号、授权或 API Key。

支持 xlsx 吗？

支持。安装 amzleak[xlsx] 扩展即可读取工作簿；不装扩展也能处理 CSV、TSV 和 TXT。

币种怎么处理？

不做汇率换算。只有同币种金额会并入总账；检测到混合币种时，结果会明确提示，不会强行相加。

和网页版什么关系？

网页版适合免安装快速查看；CLI 适合不想上传报表、需要脚本化或批量检查的场景。两边都提供三表合并与单表审计入口。

为什么不给我“预计能多赚钱”的数字？

因为那会把可追回现金、存量占用和已发生损失混成一个无法核验的数。这里只展示能回到报表行的金额，并明确标注口径差异。

本页与 CLI 均为 MIT 开源；报表全程本地解析，不上传。
